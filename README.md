# Carolina Media & Protest Research Group (CMAP)

Website for the Carolina Media & Protest Research Group, a collection of faculty, graduate students, and undergraduates affiliated with the University of North Carolina, Chapel Hill Sociology Department studying collective action and the media.

## Built With

- [Hugo](https://gohugo.io/) - Static site generator
- [Wowchemy](https://wowchemy.com/) - Research group theme

## Local Development

```bash
hugo server
```

## Content Structure

- `content/authors/` - Team member profiles
- `content/publication/` - Research publications
- `content/project/` - Research projects
- `content/presentation/` - Conference presentations
